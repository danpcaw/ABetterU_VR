# Submission form: things to remember to say

Checklist for the free-text boxes (description, tech notes, anything about data). Tick each when it is in the form.

- [ ] **Food data is UK-based.** Say it in the description or technical notes, for example: "Foods, restaurant items and calories come from the A Better U UK food database (UK supermarket, restaurant and CoFID items). Judges in the US may see different portions and calories for the same product, for example a McDonald's Big Mac. The Food Diary and the food picker say so on screen."
- [ ] **Existing versus new:** the web app, phone app and Supabase database existed before the hackathon; the whole VR app, the Atlas agent and the Meta integrations are new. Labelled in the demo video.
- [ ] **Meta tools used:** Muse Spark, Muse Voice Transcribe, Muse Image, SAM 3.1.
- [ ] **AI coding tools used:** Claude Code (most code), Muse Code, OpenAI Codex. Details in docs/AI_USAGE.md.
- [ ] **Judge access:** Judge Instant Login on the login screen. The APK is supplied privately; keys are bundled, so rotate them after judging (Nov 10).
